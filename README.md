# UsedCarAI 🚗

Used-car listing price estimation for the Thai market using Random Forest, Linear Regression, and a hybrid comparable-price approach, with a Gradio web interface. Developed for CPE-306. Prices are displayed in Thai Baht (THB).

## Features

- Random Forest and Linear Regression predictions
- Hybrid estimates: 50% Random Forest and 50% comparable market price, falling back to Random Forest when fewer than three usable comparables are available
- Dependent brand, model, and sub-model dropdowns
- Comparable vehicle details and a rule-based reliability indicator
- Notebooks for cleaning, training, model comparison, and reliability auditing

## Installation

Tested on Linux Mint with Python 3.12. Install Git and Python's venv support before starting.

```bash
git clone https://github.com/WolkenRegen/UsedCarAI.git
cd UsedCarAI
python3.12 -m venv ML
source ML/bin/activate
python -m pip install -r requirements.txt
```

The virtual environment and kernel installation are local to each machine and are not included in the repository.

## Run the application

From the repository directory:

```bash
source ML/bin/activate
python app/prediction_app.py
```

Open **http://127.0.0.1:7860**. Press `Ctrl+C` in the terminal to stop the server. The application loads the included pretrained models; retraining is not required.

To launch through a notebook, open `UsedcarAi/predict_used_car_price.ipynb` in VS Code with the Python and Jupyter extensions, choose `ML/bin/python` as its kernel, and run all cells. Keep the application process running while using the interface. Public tunneling is disabled by default.

## Notebook workflow

Select the `ML` Python environment for each notebook and run notebooks **01 → 06** in order when reproducing the full workflow.

| Notebook | Purpose |
| --- | --- |
| 01 | Clean raw listings and generate the cleaned dataset and data splits |
| 02 | Train and evaluate Random Forest |
| 03 | Train and evaluate Linear Regression |
| 04 | Build and evaluate Hybrid estimates |
| 05 | Compare model evaluation results |
| 06 | Audit prediction reliability |

Running the workflow writes generated data, models, metrics, predictions, and figures into `dataset/` and can replace existing artifacts. Random Forest tuning may take considerable time.

The full cleaned CSV and evaluation outputs are generated by the workflow and are not included. Notebook 05 requires prediction outputs from notebooks 02–04; notebook 06 requires the cleaned dataset from notebook 01 and model artifacts. The application uses `data/processed/train.csv` for dropdown choices when the cleaned CSV is unavailable.

## Local paths

Notebooks discover the project by looking for `app/` and `dataset/` in the current directory or its parents. Start VS Code from the repository directory. When using a different working directory, configure the checkout location before launching your notebook environment:

```bash
export USEDCAR_PROJECT_DIR="/absolute/path/to/UsedCarAI"
```

The app finds `dataset/` relative to its own source file. Set `DATASET_DIR` to override the dataset location for both the app and notebooks. Linux paths are case-sensitive: the notebook directory is `UsedcarAi`, and the model directory is `dataset/models`.

## Data and limitations

The included data is based on One2Car Thailand listings. Source provenance is recorded in `dataset/data/thailand/raw/one2car_thailand_20260822.source.json`. Model evaluation details are stored in each model's metadata JSON.

- Estimates represent listing prices, not guaranteed transaction prices.
- Accuracy depends on data quality and coverage.
- Linear Regression can produce negative predictions for some inputs.
- Reliability scores are rule-based indicators, not calibrated probabilities of accuracy.
- Vehicle age uses the reference year 2026 configured in the project.

Only load saved `.joblib` models from sources you trust.
